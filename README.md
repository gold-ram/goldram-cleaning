# Gold Ram Cleaning Services – Website Project

A fully responsive, multi-page website created for **Gold Ram Cleaning Services**, a family-owned residential and commercial cleaning business. This project was developed as part of a web design course and demonstrates semantic HTML5, modern CSS3 techniques, accessibility best practices, and clean UI/UX design.

---

## 🌟 Live Website
Visit the published website here:

👉 **https://gold-ram.github.io/goldram-cleaning/**

---

## 🧼 Project Overview

The website includes the following pages:

### **🏠 Home Page**
- Hero section with branding  
- Overview of cleaning services  
- Pricing tiers  
- A fully styled **service comparison table**  
- Testimonials and visual elements

### **🧍 About Page**
- Mission statement  
- Company values  
- Family-owned focus  
- Polished layout with imagery and brand colors

### **📩 Contact Page**
- Professional quote-request form  
- Required form fields  
- Fieldsets and input validation  
- Clear layout and mobile-friendly structure

---

## 🎨 Design & Technologies Used

### **Languages**
- HTML5  
- CSS3  

### **CSS Features**
- CSS variables (custom color palette: navy & gold)  
- Responsive grid layouts  
- Media queries for mobile/tablet  
- Custom cards, buttons, pricing boxes, and tables  
- Accessibility-support classes like `.sr-only`

### **Accessibility**
- Skip link: *“Skip to content”*  
- ARIA labels and roles  
- Semantic headings (H1–H3)  
- Color contrast aligned with WCAG recommendations  
- Captioned comparison table
